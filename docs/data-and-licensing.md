# 数据来源、凭据与许可

系统仅调用官方 CTP MdApi 的行情订阅能力，不包含交易下单、绕过登录、破解、账号代注册或非官方数据采集。

使用前需要由操作者确认：账号为本人或已获授权使用；前置来自官方渠道；平台服务条款允许其具体使用场景和服务器所在地的访问；行情数据的存储、研究、跨境处理及任何再分发均有相应依据。新加坡部署本身不构成授权，也不能由代码配置代替法律判断。

参考官方来源（前置、条款和服务时间可能更新，以实际登录页面为准）：

- [SimNow 产品与服务](https://www.simnow.com.cn/product.action)：区分标准仿真与 API 测试环境。
- [SimNow 注册与协议](https://www.simnow.com.cn/index2.jsp)：注册、使用及隐私条款。
- [SimNow API 下载](https://www.simnow.com.cn/static/apiDownload.action)：SDK 的官方获取入口及相关说明。

API 测试环境只用于程序联调。标准仿真环境的数据也不应未经核实就称为真实逐笔数据；本系统接收的是快照，报告中的来源标记来自操作者配置。不得把合成测试的统计结果当作市场发现。

仓库中的研究算法、品种参数与测试夹具是固定的开发输入；部署变量、服务器地址、当前订阅合约、账号密码、API Key、生成令牌、实际行情与报告只保存在部署端。测试用账号字符串、保留测试地址和合成行情不对应真实用户。许可证的著作权署名和 Git 作者归属保留，不属于运行账号凭据。

默认不持久保存账号密码，开启“记住”才保存到权限 0600 的本地文件。明文持久化不是加密保险箱；主机管理员、卷备份和磁盘快照仍可能访问，需自行控制权限和保留期限。程序不输出密码、面板令牌或账号到应用日志。CTP 原生组件可能在本地会话目录产生文件，整个数据卷都应按私有数据管理。

Git 忽略和 Docker 上下文过滤不能代替提交检查，尤其不要强制添加被忽略的文件。运行 `python3 scripts/check_repository.py` 检查待提交路径和常见私密内容；这是有限规则检查，不是泄露检测的完整保证。
